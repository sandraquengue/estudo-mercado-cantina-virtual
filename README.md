# Dashboard de Estudo de Mercado - NaCantina

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um dashboard interativo para análise de um estudo de campo realizado na Centralidade do Capari, com o objetivo de avaliar a viabilidade de desenvolvimento de uma cantina virtual para atender às necessidades da comunidade local.

O estudo foi realizado devido às dificuldades enfrentadas pelos moradores em encontrar produtos essenciais, causadas pela escassez de cantinas na região. O dashboard apresenta os principais resultados obtidos através dos dados recolhidos junto aos entrevistados.

## Objetivo

Analisar as necessidades da comunidade, identificar padrões de consumo e avaliar o interesse dos moradores na implementação de uma cantina virtual na Centralidade do Capari.

## Ferramentas Utilizadas

- Power BI
- Power Query
- Excel

## Preparação dos Dados

- Filtragem e organização dos dados recolhidos através do Excel;
- Limpeza e tratamento dos dados antes da análise;
- Preparação da base de dados para criação do dashboard.

## Indicadores Analisados

- Contagem de expectativas dos entrevistados;
- Tipos de produtos mais procurados pela comunidade;
- Dificuldade para encontrar produtos;
- Grau de interesse na criação da cantina virtual;
- Frequência de utilização do telefone;
- Distribuição dos entrevistados por género;
- Distribuição dos entrevistados por faixa etária.

## Análises Disponíveis

- Necessidades de produtos da comunidade;
- Avaliação da dificuldade de acesso aos produtos;
- Interesse dos moradores pela solução proposta;
- Perfil dos participantes do estudo;
- Análise do comportamento relacionado ao uso de telefone.

## Funcionalidades do Dashboard

- Visualização interativa dos resultados da pesquisa;
- Análise do perfil dos entrevistados;
- Identificação das principais necessidades da comunidade;
- Apoio à tomada de decisão para desenvolvimento do negócio.

## Competências Demonstradas

- Limpeza e transformação de dados utilizando Excel e Power Query;
- Organização e preparação de bases de dados;
- Desenvolvimento de dashboards interativos em Power BI;
- Análise exploratória de dados;
- Análise de comportamento do consumidor;
- Transformação de dados de pesquisa em insights estratégicos.
